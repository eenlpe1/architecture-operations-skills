# Domain documentation

This repository uses a single context. Read root `CONTEXT.md` for its vocabulary and relevant decisions under `docs/adr/` before changing behavior. Missing domain documents do not block work; create them only when a real term or decision needs recording.

Use the glossary's terms consistently. Surface conflicts with an existing ADR rather than silently reversing it. Skill-specific operational notes and private incident records are not part of the domain glossary.
