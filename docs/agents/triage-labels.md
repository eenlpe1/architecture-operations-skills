# Triage labels

| Canonical role | Local Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluates the task |
| needs-info | needs-info | Required information is missing |
| ready-for-agent | ready-for-agent | Specified and ready for agent work |
| ready-for-human | ready-for-human | Human implementation or judgment needed |
| wontfix | wontfix | Will not be actioned |

Use these values in local task files. Creating remote labels is a separate action.
